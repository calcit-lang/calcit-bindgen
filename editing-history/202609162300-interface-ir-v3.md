# Support Interface IR v3 / 支持 Interface IR v3

## 中文

- 在保持 v2 向后兼容的同时，接受 native 与 Component Interface IR v3 schema、document 和 export envelope。
- native v3 接受显式整数与浮点宽度；native v2 继续拒绝这些 refinement。
- 读取并校验 Component v3 的 `invocation`。兼容性比较将 v2 缺省 invocation 视为 `sync`，避免 v2 到 v3 的同步升级被误报为 breaking。
- 当前 Component packaging backend 仍只支持同步调用；遇到 `async` 时在写入产物前给出明确、带 definition path 的失败。
- 增加 v3 JSON/envelope、数值宽度、invocation 与 async packaging 回归测试，并使用 Calcit 0.15.2 导出的真实 `calcit.std` native IR v3 验证 loader 和 Rust generator。

## English

- Accept native and Component Interface IR v3 schemas, documents, and export envelopes while preserving v2 compatibility.
- Accept explicit integer and floating-point widths in native v3 while continuing to reject them in native v2.
- Read and validate Component v3 `invocation`. Compatibility comparison normalizes a missing v2 invocation to `sync`, avoiding a false breaking change for synchronous v2-to-v3 upgrades.
- Keep the current Component packaging backend synchronous-only; reject `async` before artifact writes with a definition-specific path.
- Add v3 JSON/envelope, numeric-width, invocation, and async-packaging regression coverage, and validate the loader and Rust generator against real native IR v3 exported from `calcit.std` by Calcit 0.15.2.
