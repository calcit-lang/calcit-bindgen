# calcit-bindgen 0.1.9 release / calcit-bindgen 0.1.9 发布

2026-09-23 22:27 +0800

## 中文

PR #56 已将正式 WASI v0.3.1 command world 及依赖 WIT 合并到 main；精确 main SHA 的 Check 工作流已通过，其中 Linux 使用 Wasmtime 49.0.0 实际运行了 0.3.1 command Component。0.1.8 发布早于该合并，故发布 0.1.9 供 Calcit #1295 使用。此次只升级 crate 自身版本和 lockfile metadata，不扩张公开 API。

## English

PR #56 merged the official WASI v0.3.1 command world and dependency WIT into main. Check passed on the exact main SHA, including real execution of the 0.3.1 command Component with Wasmtime 49.0.0 on Linux. Version 0.1.8 predates that merge, so release 0.1.9 for Calcit #1295. This changes only the crate version and lockfile metadata, with no additional public API.
