# WASI 0.3.1 标准输出 ABI 回归 / WASI 0.3.1 stdout ABI regression

2026-09-23 23:32 +0800

## 中文

为 Calcit #1266 增加最小 Canonical ABI 回归：以官方 WASI 0.3.1 WIT 包装 stdout 字节流命令，并在 Wasmtime 49.0.0 上运行 1 MiB 输出。该测试验证 stackful async 命令入口、同步 stream 写入、部分写入循环和 stream/future 所有权释放。Wasmtime 当前需要显式打开 `component-model-more-async-builtins` 与 `component-model-async-stackful`；这不是 Calcit 表层新入口。

## English

Add a small Canonical ABI regression for Calcit #1266: package a stdout byte-stream command against the official WASI 0.3.1 WIT and run a 1 MiB output through Wasmtime 49.0.0. This covers the stackful async command entry, synchronous stream writes, partial-write loop, and stream/future ownership drops. Wasmtime currently requires the `component-model-more-async-builtins` and `component-model-async-stackful` feature switches; this does not add a Calcit surface command.
