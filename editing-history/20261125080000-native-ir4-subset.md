# 接受 Native Interface IR v4 的既有值类型 / Accept existing value types in native Interface IR v4

- Calcit 0.45.1 将 native Interface IR 升为 v4；标准库 hash 的接口只使用已有值类型，但先前版本整体拒绝 v4。
- 验证 v4 schema ID 后复用既有值类型验证、diff、生成与检查；未知类型、union 和 FfiResource 仍明确拒绝，完整 v4 支持继续由 #62 跟踪。
- 真实标准库 v4 hash 输入已生成并通过 check；与旧绑定对比仅生成文件中的 IR 版本标注变化。

Calcit 0.45.1 emits native Interface IR v4. Its standard-library hash interface uses existing value types but was previously rejected solely by version. This change validates the v4 schema ID and reuses the existing value-type validation, diff, generation and checks; union and FfiResource remain explicitly unsupported under #62. The actual standard-library v4 hash export generates and checks successfully, with only the IR-version header changed in the Rust bindings.
