# Release calcit-bindgen 0.1.2 / 发布 calcit-bindgen 0.1.2

## 中文

- 将 crate 版本提升到 0.1.2，正式发布 Wasmtime 47 下有界、类型化的 WASI HTTP host adapter。
- 默认不授予网络能力；origin 白名单、响应大小上限和结构化错误保持显式。
- 同步文档中的依赖版本，使 Calcit 端到端验证可以固定使用正式版本而非 Git 分支。

## English

- Bump the crate to 0.1.2 to publish the bounded typed WASI HTTP host adapter for Wasmtime 47.
- Keep network access denied by default, with explicit origin grants, response limits, and typed errors.
- Update the documented dependency version so Calcit end-to-end validation can pin a release instead of a Git branch.

## Verification / 验证

- `cargo fmt --check`
- `cargo clippy --all-targets --all-features -- -D warnings`
- `cargo test --all-features`
- `cargo package --all-features`
