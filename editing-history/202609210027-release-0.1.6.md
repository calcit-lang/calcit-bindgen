# Release 0.1.6 / 发布 0.1.6

## 中文

- 发布 generated host 在 Cargo 产生 `Cargo.lock` 和 `target/` 后仍可重复 `check` 与安全重新生成的修复。
- 严格拒绝将 nominal `%::` enum 当作 WIT `option` / `result` 边界值，避免类型名被静默丢弃。
- CI 默认执行完整 `wasmtime-http` feature 测试，再运行真实 HTTP Component 验收。

## English

- Release repeatable generated-host checking and regeneration after Cargo creates `Cargo.lock` and `target/`.
- Strictly reject nominal `%::` enums at WIT `option` / `result` boundaries instead of silently discarding their type names.
- Run the complete `wasmtime-http` feature suite in CI before the real HTTP Component acceptance test.
