# Release calcit-bindgen 0.1.1 / 发布 calcit-bindgen 0.1.1

## 中文

- 将 crate 版本提升到 0.1.1，发布自 0.1.0 以来已经合并的确定性生成、Component packaging 与 Interface IR v3 支持。
- 保持 Interface IR v2 向后兼容；使用 v3 的消费者可以依赖正式版本，不再固定 Git revision。

## English

- Bump the crate to 0.1.1 to release the deterministic generation, Component packaging, and Interface IR v3 support merged since 0.1.0.
- Preserve Interface IR v2 compatibility so v3 consumers can depend on a released version instead of pinning a Git revision.

## Verification / 验证

- `cargo fmt --check`
- `cargo clippy --all-targets -- -D warnings`
- `cargo test`
- `cargo package`
