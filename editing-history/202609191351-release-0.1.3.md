# Release calcit-bindgen 0.1.3 / 发布 calcit-bindgen 0.1.3

## 中文

- 将 crate 版本提升到 0.1.3，发布 Component Interface IR v4 支持。
- 为作用域化 `ReadableByteStream` 生成 WIT `stream<u8>`，并限制为 async Component export 的直接参数。
- 在生成前拒绝 import、返回值、容器以及 Struct/Enum 声明中的 stream，避免 raw readable handle 逃逸。
- 通过真实 Wasmtime `StreamReader<u8>` 调用验证 Canonical ABI builtins 与 readable-end 清理。

## English

- Bump the crate to 0.1.3 to publish Component Interface IR v4 support.
- Render scoped `ReadableByteStream` values as WIT `stream<u8>` and restrict them to direct async Component export parameters.
- Reject streams in imports, results, containers, and Struct/Enum declarations before generation so raw readable handles cannot escape.
- Exercise the Canonical ABI builtins and readable-end cleanup through a real Wasmtime `StreamReader<u8>` call.

- `cargo clippy --all-targets --all-features -- -D warnings`
- `cargo test --all-features`
