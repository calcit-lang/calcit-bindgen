# 适配 Wasmtime 48 / Adapt to Wasmtime 48

2026-10-25 10:40 +0800

## 中文

Calcit 的 dependabot PR #2346 把 dev-dependency `wasmtime` 升到 48.0.7，但 bindgen 仍固定 47.0.4，`wasmtime_http::add_to_linker` 收到的 `Linker` 类型不一致导致测试编译失败。本次把 `wasmtime`、`wasmtime-wasi`、`wasmtime-wasi-http` 一起升到 48.0.7，并适配 API 变化：preopen 改用 `FsPerms`；出站请求改用 `wasmtime_wasi_http::default_send_request` 与 `RequestOptions`，TLS 由 URI scheme 决定，hyper 连接 future 在读取 body 期间由独立 task 驱动并在返回时 abort；body 与传输错误统一为 `wasmtime_wasi_http::Error`。48 的默认发送器不再补 `Host`（47 会补，guest 又不能设置这个 forbidden header），因此由 adapter 依据已校验 URI 的 authority 显式设置，并让本地 HTTP 测试服务器在缺少 `Host` 时返回 400。crate 版本升到 0.1.10，文档示例同步为 0.1.10 与 Wasmtime 48。公开 API 不变。

## English

Calcit's dependabot PR #2346 bumps the `wasmtime` dev-dependency to 48.0.7, while bindgen still pins 47.0.4, so `wasmtime_http::add_to_linker` receives a mismatched `Linker` type and the tests fail to compile. Bump `wasmtime`, `wasmtime-wasi`, and `wasmtime-wasi-http` together to 48.0.7 and adapt to the API changes: preopens use `FsPerms`; outgoing requests use `wasmtime_wasi_http::default_send_request` with `RequestOptions`, TLS follows the URI scheme, and the hyper connection future runs in its own task while the body is read and is aborted on return; body and transport errors use `wasmtime_wasi_http::Error`. The 48 default sender no longer adds `Host` (47 did, and guests cannot set this forbidden header), so the adapter sets it from the validated URI authority, and the local HTTP test server now answers 400 when `Host` is missing. Bump the crate to 0.1.10 and update the docs example to 0.1.10 with Wasmtime 48. No public API change.
