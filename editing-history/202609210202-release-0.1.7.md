# Release 0.1.7 / 发布 0.1.7

## 中文

- 发布 preopen-backed Cirru EDN 参数文件与结果文件支持。
- 发布生成宿主的稳定业务退出码、严格 capability 边界与防路径替换竞态的句柄访问。
- 保持现有 `validate`、`generate`、`check` 与生成 host 入口，不增加平行顶层命令。

## English

- Release preopen-backed Cirru EDN argument and result file support.
- Release stable business exit codes, strict capability boundaries, and handle-based access that prevents path-replacement races in generated hosts.
- Keep the existing `validate`, `generate`, `check`, and generated-host entry points without adding a parallel top-level command.
