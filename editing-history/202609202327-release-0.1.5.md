# Release 0.1.5 / 发布 0.1.5

## 中文

- 发布 generated Wasmtime host 的严格 Cirru EDN 参数与结果 codec。
- 发布 Calcit 0.18.0 真实 HTTP Component 的成功、默认拒绝与响应超限 CI 验收。
- 保持同一个 `generate` / `check` 入口、default-deny capability 与零参数 Unit 向后兼容。

## English

- Release the generated Wasmtime host's strict Cirru EDN argument and result codec.
- Release CI acceptance for success, default denial, and response limits against a real Calcit 0.18.0 HTTP Component.
- Preserve the same `generate` / `check` entry points, default-deny capabilities, and zero-parameter Unit compatibility.
